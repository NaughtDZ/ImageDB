# 2026-10-17 稳定性维护

保留 Web + Python + SQLite 架构，不迁移 WinUI 3/WPF。本轮没有修改正式数据库、媒体文件或设置，没有重启生产实例，没有数据库结构迁移，也没有自动提交/推送。

## 已实现

### 数据保护

- [移动与回收恢复](<../app/server.py>)：移动失败保留记录与标签；同名避让同步 filename/path/folder_id；磁盘目标和库内路径都参与冲突检查。移动不覆盖目标，跨盘复制成功后才移除源文件；写库失败尝试退回文件。回退被新文件占位等原因阻止时，明确报告保留下来的文件路径，不覆盖新文件。
- 应用回收站先保存恢复记录再移动，暂存名字使用短的随机唯一名称。暂存文件缺失/不可读或标签快照不合法时，不再假恢复成功。恢复的媒体/标签/回收站删除在一个事务中完成；失败退回暂存位置，保留恢复线索。
- 用户显式回收不存在的文件时，先新鲜检查根目录可达；可确认缺失才清理记录，并单独报告 records_only；离线/未知保留记录。普通移动绝不走该删除分支。
- [图片缩略图](<../app/media.py>)：数据库保存 EXIF 校正后的原图尺寸，而不是缩小后的尺寸。
- [标签写入](<../app/imagetag.py>)与[打标管理器](<../app/tagging/manager.py>)：验证整张图片的标签再进入事务，只覆盖同来源旧关联，不接管手动或其他来源关联；标签创建冲突安全；保留 0 置信度，拒绝非有限值。
- 迁移侧车以只读连接读取；损坏条目跳过并返回 errors，合法空列表仍可表示清空旧导入标签；失败图片原子回滚，其他有效图片可继续，界面明确显示部分失败。
- [扫描与恢复](<../app/library.py>)：普通名字匹配走无逐文件 stat 快路径，仅在名字不一致时确认真实文件身份。仅大小写改名保留 ID/标签，不能证明是同一文件时保守保留，不全局小写化。子目录先导入后再导入父目录，可安全补父关系且拒绝循环。
- 清理丢失记录重新确认根目录、目录快照及文件缺失，保留已恢复/无法确认的记录；按目录缓存探测避免每条媒体重复 scandir，返回 retained/live/unknown 汇总。

### 界面与任务

- [画廊](<../web/js/gallery.js>)先重置页码再发请求，只接受最新列表响应；[目录树](<../web/js/tree.js>)和[元数据面板](<../web/js/metadata_panel.js>)也拒绝过期响应。
- 选择、区间选择、清除选择及框选只更新选中样式，不重建卡片/图片节点；缩略图回调检查请求身份、取消状态与目标节点，避免旧请求干扰新页。
- 每页条数统一为 10–200，首次加载前恢复并修正保存值。[页面](<../web/index.html>)同步上限，并移除不存在的图标引用。
- [手动标签编辑](<../web/js/tags.js>)固定编辑目标 ID，读取新数据而非旧画廊副本；详情读取最多并发 8 个，写入串行，更新后保留选择；失败刷新实际状态。
- [通用任务进度](<../web/js/jobprogress.js>)关闭后令在途回调失效；[打标窗口](<../web/js/tagger.js>)保留任务 ID，关闭再打开可重连，重复启动受保护，轮询不重叠。
- [后台任务表](<../app/jobs.py>)只淘汰已结束任务；扫描原子认领同类独占任务。打标异常/线程启动失败有终态处理，取消不会被晚到完成状态覆盖。
- [标签计数](<../app/tagstats.py>)用变更版本号避免吞掉并发通知，200 ms 合并短时变更；已初始化的合法空缓存不再反复重建。

## 生效与回退

1. 用户自行退出旧 ImageDB 实例，再重新启动；仅刷新浏览器不能加载 Python 变化。
2. 随后刷新页面，确保静态脚本与后端版本一致。
3. 代码发布按用户明确授权提交/推送，不包含本地媒体库或临时测试产物。回退代码不会要求降级数据库结构；但不能因此省略正式库备份。
4. 备份运行中的 SQLite 应使用 SQLite backup API 或停止程序后做一致性备份，不能只复制活动 WAL 模式下的主库文件。

## 明确保留的边界

- 不自动合并历史重复记录，也不批量重读全库修复旧尺寸；新生成缩略图写正确尺寸。
- 本次文件大小写修复不包含目录整体改名迁移；身份信息不足时保守延迟新增或恢复。
- 文件系统和数据库不是一个事务；普通错误有补偿，但不承诺突然掉电/进程被强杀时完全原子。磁盘在最终探测后被外部修改仍存在不可消除的窗口。
- 文件操作串行化与任务独占均为进程内保护，不是跨实例锁；建议同一库只运行一个实例。
- 打标窗口重连支持同一页面内关闭/重开，不包括 F5 后自动找回任务。取消为协作式，不强制中断模型推理。
- 手动多媒体标签更新按图片提交，不是跨全部图片的全有全无事务；部分失败会告知并刷新真实结果。
- 浏览器取消图片加载不保证后端解码工作立即停止；仍使用浏览器自身的缩略图网络调度。
- 本轮未重跑网络盘大库性能基准，不宣称新的秒数或加速倍数。主要性能收益来自减少 DOM 重建、单图事务、缓存合并与有界并发。
